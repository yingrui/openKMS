Hierarchical map of terms (stored in PostgreSQL as `knowledge_map_nodes`) and their links to channels / wiki spaces / article channels (`knowledge_map_resource_links`). Rendered as a force graph on the signed-in home page.

### Overview (A2UI canvas + NDJSON designer)

Presentational source of truth is **`knowledge_map_overview_composition`** storing `{ format: "a2ui_v0_9", messages: [...] }`—not HTML. Browse returns live tree + labeled resources + those A2UI messages (`GET /api/knowledge-map/overview`). If no row is published (or legacy composition JSON is present), the server synthesizes a default A2UI surface from the forest. The middle pane runs `@a2ui/web_core` `MessageProcessor` against the openKMS KM catalog. Designer chat uses the same NDJSON event dialect as map-html (`delta`, `tool_start` / `tool_end`, `done`, `error`) via `POST /api/knowledge-map/overview/designer/chat`; tool **`set_a2ui_messages`** updates the working canvas (`tool_end.output` / `done.a2ui_messages`). On the Overview tab, layout height matches the former HTML designer (`knowledge-map-page--html-designer-full-height`).

Legacy **Map HTML** (`knowledge_map_html_artifact`, `map-html*` routes, `surface=knowledge_map_html`) is deprecated for the SPA Overview tab but APIs remain until a later cleanup.
